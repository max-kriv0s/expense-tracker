# Standup Report

Формирует краткий standup-отчёт о работе за вчерашний день на основе git-истории.

## Алгоритм

1. **Определи вчерашнюю дату** через `date`.

2. **Собери коммиты за вчера**:
   ```bash
   git log --all --after="yesterday 00:00" --before="today 00:00" \
     --format="%H %s" --author="$(git config user.name)"
   ```
   Если автор не найден — покажи все коммиты за день.

3. **Для каждого коммита** получи краткое содержание:
   ```bash
   git show --stat <hash>
   ```

4. **Если коммитов нет** — сообщи об этом явно и предложи расширить диапазон до последних 3 дней.

5. **Сформируй отчёт** в формате ниже.

---

## Формат отчёта

Два коротких абзаца на русском языке:

```
**Standup — <DD.MM.YYYY>**

<Первый абзац: что именно было сделано — суть изменений, без перечисления файлов и хэшей коммитов. Группируй по смыслу.>

<Второй абзац (если есть что добавить): контекст, нерешённые вопросы, что планируется дальше. Если нечего добавить — один абзац.>
```

---

## Правила

- Только русский язык, живым понятным текстом.
- Не перечислять файлы, хэши, типы коммитов.
- Группировать изменения по смыслу, а не по коммитам.
- Писать активно: «реализован», «добавлен», «исправлен» — не «был добавлен».
- Не запрашивать подтверждение — просто выводить отчёт.
