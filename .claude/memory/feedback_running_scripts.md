metadata:
  type: feedback
---

Не запускать сложные скрипты, скриншот-автоматизацию, CDP-скрипты и многошаговые команды без явного подтверждения пользователя.

**Why:** Пользователь хочет контролировать то, что запускается на его машине, и не успевает читать длинные команды до их выполнения.

**How to apply:** Для верификации UI-изменений — предложить пользователю запустить сервер самому и прислать скриншот. Для простых команд (npm run dev, git status, curl) — спрашивать не нужно. Для скриптов с созданием файлов, установкой пакетов, CDP/браузерной автоматизацией — останавливаться и объяснять что делает команда, прежде чем запускать.
