Предпочитает простую, незагромождённую структуру проекта — без лишних слоёв абстракции.

**Why:** Проект учебный, overhead от workspaces и shared-packages не оправдан на старте.

**How to apply:** Не предлагать монорепо-инфраструктуру (nx, turborepo, workspace packages) без явного запроса. Начинать с плоской структуры.

---

## Не коммитить без явного согласия

После завершения задачи показать изменения и дождаться слова «коммить» / явного одобрения.

**Why:** Пользователь хочет проводить ревью перед созданием PR.

**How to apply:** Никогда не вызывать `git commit` автоматически по завершении задачи — только по прямому запросу.
